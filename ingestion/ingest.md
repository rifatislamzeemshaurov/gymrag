# Ingesting a supplement catalog

How the catalog PDFs in `data/` become the Qdrant collection GymRAG answers from, and what to change when the catalog changes.

```
data/*.pdf ──► split per product ──► clean + repair spec tables ──► data/_staged_products/*.md ──► LLM metadata extraction ──► Qdrant (dense + sparse)
```

## Run it

```bash
cd ingestion
uv run --project ../backend --with jupyterlab jupyter lab rag_pipeline.ipynb   # or open it in VS Code
```

Run every cell top to bottom. It reads `../.env` for `OPENAI_API_KEY`, `QDRANT_URL` and `QDRANT_API_KEY`.

`rag_pipeline.yaml` has `force_recreate: true`, so each full run **drops and rebuilds** the `gymrag-supplements-openai-qdrant` collection. The catalog therefore always matches the PDFs exactly. The API (`backend/pipeline.yaml`) uses `force_recreate: false` and never writes to the collection.

## The guide layout the splitter expects

Each guide is one PDF per category, with every product as a numbered listing:

```
07. Olympus Supplements - Lean Isolate          ← "NN. Brand - Product" heading
Brand Overview: Massive gains, massive scoops.
Quantity / Servings   2 lbs / 26 Servings       ← spec table (any order)
Price                 $44.76
Protein per Serving   25g
Protein Source        Whey Isolate
Review & Efficacy
A no-nonsense isolate with clean macros...
```

PDF text extraction prints the table labels first and the values later. The notebook pairs them back up using the known label list for each category (`COMMON_LABELS` / `CATEGORY_LABELS`). If a listing's labels or values don't line up, it stops with a clear error instead of ingesting bad data.

## A. More products in an existing category

Add the listings to that category's PDF, or add another PDF in the same layout and register it in `CATALOGS` (section 2 of the notebook). Then re-run the notebook.

## B. A new category (for example `fat_burner`)

1. Put the PDF in `data/` and add it to `CATALOGS`.
2. Add its spec labels to `CATEGORY_LABELS`, for example `"fat_burner": ["Caffeine per Serving", "L-Carnitine", "Stimulant Free"]`.
3. In `ingestion/rag_metadata.yaml`:
   - add the category to the `category` field's `values`;
   - add it to rule 4 of the `prompt`;
   - add one field per new label.
4. Copy the file over `backend/metadata.yaml`. The two must stay identical.
5. In `backend/rag_engine.py`, add the category to `CATEGORIES` and `CATEGORY_FIELDS`, and add it to the category lists in `SYSTEM_PROMPT`.
6. In `frontend/components/gymrag-advisor.tsx`, add a badge to `CATEGORY_META` and labels to `SPEC_LABELS`.
7. Re-run the notebook and redeploy.
